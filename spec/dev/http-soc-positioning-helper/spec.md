# SOC 随机置位批量助手开发规格

## 定位

`http-soc-positioning-helper` 是独立的 SOC 本地 Python APP，不属于 IEB 首页工具，也不复用 IEB 或 OA Cookie。它以 Excel 活动 Sheet 表头为输入，严格串行执行飞行人员随机置位申请。

## 输入与模板

模板表头为：`序号`、`员工号`、`姓名`、`航班日期`、`出发地`、`目的地`、`航班号`、`申请原因`、`备注`、`是否需要录入`。员工号按文本归一，日期支持 Excel serial、Date 和明确的年月日文本；“是否需要录入”不是“是”的行跳过，不计入有效批次。

申请原因使用页面当前固定的 20 条静态字典，提交使用代码；模板 H 列提供同一字典下拉。站点不硬编码全量，按用户输入值调用 SOC 建议/动态航班接口；航班号从当前 `rows` 匹配并原样提交完整复合 option value。

## 执行边界

每行依次执行动态航班、人员业务校验和最终提交，最终提交最多一次。普通字段错误、无航班、航班不匹配、人员拒绝和业务失败标记该行失败并继续；登录重定向、IAM 登录页或会话失效清除凭据并停止后续行。不自动重试、删除、撤销、审批或并发。

## 结果

结果 Excel 即时保存来源行、员工、航线、航班、原因、状态和说明；结果目录被 Git 忽略。只有 JSON `message=录入成功！` 记为成功，HTTP 200 不单独作为成功依据。
