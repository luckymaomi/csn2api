# 工具首页开发规格

工具首页直接展示 `src/tool/tools-data.ts` 当前登记的 HTTP 工具入口，不提供搜索或分类切换。

仓库和首页品牌为 `csn2api`。工具名称与目标业务系统名称独立维护；飞行门户 IEB 等应用名称不随仓库品牌改名。

src/tool/tools-data.ts 是首页工具内容和独立应用导出的唯一清单，保存名称、说明、入口、发布状态和可选的 homepageState。清单中的工具全部直接进入首页和独立 ZIP 构建；新增工具不需要修改固定数量规约。

首页保留顶部导航和图案门禁结构，门禁由 src/site-visibility.ts 控制且默认关闭。顶栏只提供 API 文档、白天/暗夜模式切换和 GitHub，不提供用户手册或开发者页面。首次访问默认白天模式，选择通过共享主题设置保存在浏览器本地。

页面使用全站共享主题：颜色、边框、阴影、状态和主题值由 public/theme.css 统一提供；首页 CSS 只维护首页布局和组件特判。每项显示工具名称、用途摘要、状态小字、只读开关和下载图标。

homepageState 只有 enabled、beta、cooling 三种状态。未填写或为 enabled 时显示“已启用”；beta 显示“Beta 测试”；cooling 显示“冷却中”。该状态只作用于首页入口，工具固定 URL 和构建产物保持可访问。

生产构建在 dist/exports/ 中按工具 entry 逐项生成 ZIP，导出数量始终等于当前工具清单数量。每个 ZIP 根目录包含 index.html、独立应用脚本、离线运行时、主题和页面实际需要的库、Python 文件及依赖说明，不包含其他工具、缓存或仓库开发文件。
