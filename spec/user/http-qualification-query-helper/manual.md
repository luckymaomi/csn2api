# 飞行人员信息查询（皇帝版）用户手册

## 启动

下载独立应用并解压，在应用目录运行：

```powershell
pip install -r requirements.txt
python start.py
```

程序只在本机 `127.0.0.1` 打开工作台，不启动 Playwright 或门户浏览器。查询按输入顺序逐人执行。

## 验证 Cookie

验证成功后，凭据区会显示该 Session 对应的“员工号 · 姓名”。身份只保存在当前页面和后端进程内存，会话失效时与 Cookie 同步清除。

先在 Chrome 或 Edge 正常登录飞行门户，按 `F12` 打开 `Network`，右键已登录请求选择 `Copy`、`Copy as cURL`，把完整内容粘贴到工作台，点击“验证 Cookie”。也可以直接粘贴 Cookie Header。

验证成功后输入框会清空，当前页凭据面板显示规范化 Cookie 并提供“复制凭据”。Cookie 只保存在本地 Python 进程内存；刷新页面不会清除已验证 Session，但页面不会自动重新展示明文 Cookie。服务关闭、主动清除或门户 Session 失效后需要重新导入或粘贴验证。

## 输入与查询

Excel 需要“员工号”“工号”或“员工编码”表头，姓名可选；粘贴模式每行写六位员工号和可选姓名。人员归属查询默认覆盖在职、外部、退休、离职四种状态，重复员工号只查询第一次，无效行会显示在数据健康检查和处理报告中。

Excel 模板请在纯前端工具详情页点击“下载 Excel 模板”获取。模板带有一行合成格式示例，填写前请覆盖或删除该行；工作台仅负责上传填写后的文件。

“数据健康检查”只显示有效和无效数量，不要求人工确认，也不会自动开始查询。点击“开始查询”时会重新读取当前输入，并按人员顺序逐人查询：

- 基础信息：基本信息、教育经历、工作经历、职称信息、家庭信息。
- 技术等级。
- 运行资格：默认包含当前和历史资格，等价于门户勾选“查看历史资格”。
- 训练检查记录：培训记录（自动遍历全部分页）和训练经历（一次读取全部返回）；不读取历史记录。

逐人结果显示页面姓名、基础信息/技术等级/运行资格/培训记录/训练经历五类条数和状态。向上滚动日志或结果列表后，页面保持当前位置；滚回底部后恢复自动跟随。单人失败不会终止整批。

“停止查询”不会强行打断已发出的 HTTP 请求；当前人员返回后不再查询下一人，并保存已经取得的结果。

## 结果与下一批

- `处理报告`：输入行号、员工号、输入姓名、页面姓名、身份核对、五类记录数量、状态和说明。
- `基础信息`、`技术等级`、`运行资格`、`培训记录`、`训练经历`：按模块查看明细，运行资格包含当前和历史记录；所有明细行带员工号和页面姓名，基础信息保留分区与记录序号，训练记录保留来源页码。
- `汇总`：查看输入来源、总数、成功、失败、输入错误和中断状态。
- 结构化 JSON：与 Excel 使用同一批数据，便于后续程序处理。
- 文本报告：快速查看本轮汇总。

每个人完成后结果 Excel 会立即保存。批次结束后可下载 Excel、JSON 和文本报告；可直接换 Excel 或粘贴内容继续下一批，当前 Session 会保留到门户登录失效或服务关闭。

## Agent 接口

Agent 可调用 `POST /api/start` 一次完成 Cookie 验证、数据检查和查询。Excel 使用 `excelName` 与 `excelBase64`，粘贴输入使用 `pastedText`；通过 `GET /api/status` 轮询，通过 download 接口获取 Excel、JSON 和文本报告。
