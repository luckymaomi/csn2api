# SOC 随机置位批量助手

## 使用流程

1. 在 SOC 已登录随机置位页面的 Network 中复制一条 cURL，粘贴到“登录凭据”，点击“验证凭据”。
2. 下载录入模板，填写员工、航班日期、出发地、目的地、航班号、申请原因、备注和“是否需要录入”。申请原因从模板下拉选择。
3. 上传 Excel，点击“数据检查”，确认无误后点击“开始录入”。
4. 查看逐条结果；普通异常会标记失败并继续，会话失效会停止后续请求。
5. 批次完成后下载结果 Excel。

## 填写说明

航班号应填写页面动态列表中的显示航班号，例如 `CZ1234`；工作台会按当天出发地和目的地重新获取完整航班值。日期按业务日期填写，备注不超过 24 个字符。模板中“是否需要录入”为“否”的行会跳过。

工作台只做随机置位提交，不提供自动删除、撤销、审批或并发执行。真实提交前必须确认当前员工、日期、航线、航班、原因、备注和动作。
