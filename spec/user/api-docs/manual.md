# API 文档用户手册

飞行门户的“查询完整飞行经历时间页”输入员工号和姓名，返回汇总、历史合计、年度及月份全部数据行和原表头，无需输入日期。

从工具首页顶栏打开“API 文档”。该入口不占用工具卡片；页面左侧按飞行门户、OA、SOC 和 CAAC 分组当前 catalog 中的 GET/POST 接口，Cookie 管理统一展示各系统的登录网址、建议抓取请求和获取步骤。系统和模块都可以用箭头展开或收起。

手机访问时，页面依次显示使用状态、搜索与导出操作、接口目录、文档和调试区域；顶部操作自动排成两列，不需要横向拖动页面。字段较多的参数表和响应表仍可在表格区域内左右滚动。

## Cookie

飞行门户的运行资质人员名册接口已加入“飞行人员信息”目录。目录中的生产请求按单个运行资格调试；动态筛选页按“字段、是否多选、选项值、选项名称”展示，普通人员清单导出按实际 Excel 表头展示全部数据行。逐项查询、人数核对和四列 Excel 合并由独立的“运行资质人员名册”工作台执行。

飞行门户的训练安排目录提供动态训练类别、单页请求和按周/月/年遍历分页的只读调试入口。区域默认配置、跨类别汇总和 Excel 明细由独立的“训练安排查询（HTTP版）”工作台执行。

Cookie 管理右侧按 catalog 顺序纵向排列各系统区域，各套凭据互不共享；右侧区域可以独立滚动。

IEB：打开 `https://ieb.csair.com/index/index` 并登录，在 F12 Network 中选择任意 `ieb.csair.com` 已登录请求，右键 Copy as cURL 后粘贴验证。`JSESSIONID` 与 `iebJSid` 为 HttpOnly，普通 `document.cookie` 无法完整读取。

OA：打开 `https://work.csair.com/oaw/work/my-dealt-with/schedule-list?sourceType=wait` 并登录，确认待办列表已显示；在 F12 Network 筛选 `query/waiting`，选择 `POST https://work.csair.com/oai/work/box/query/waiting` 并 Copy as cURL。优先粘贴完整 cURL，使本地执行器同时取得 Cookie、User-Agent 和待办 JSON 模板。Windows 和 Linux cURL 均可使用；经过聊天或富文本后出现的等价 Markdown URL、`\_`、`\*` 和 `\--data-raw` 会在解析前还原。

SOC：打开 `https://soc.csair.com/opws-web/pages/public/soc.jsp?f=2&s=11&t=1` 并进入随机置位申请页面；在 F12 Network 选择随机置位页面或其 Fetch/XHR 请求，Copy as cURL 后粘贴验证。SOC 至少需要当前有效的 `JSESSIONID`，建议保留完整 Cookie Header；它与 IEB、OA 会话完全独立。

验证成功后对应系统区域显示当前使用人、可复制的规范化 Cookie Header，并显示下一次只读保活请求的动态倒计时。IEB 和 OA 显示员工号与姓名，SOC 只显示外层页返回的当前登录姓名。保活间隔为 30-60 秒，倒计时归零后由本地执行器发送系统会话请求，成功后重新开始下一轮。刷新页面会从当前 Python 后端恢复仍有效的 Session 和规范化 Cookie；每个区域的“清除”只清该系统，服务退出后内存 Session 消失。页面不使用浏览器持久化存储保存凭据，验证失败原因会保留在对应 Cookie 卡片中。

## Cookie 文件

点击“导出 Cookie”会下载 `csn2api-cookies-*.json`，其中包含当前有效系统的规范化明文 Cookie。点击“导入 Cookie”可选择该 JSON，或内容相同的 TXT 文件；系统会逐项重新验证，失败项不会伪装成已导入。文件可同时用于独立 API 文档和 `start_all.py` 局域网模式，但只影响 API 文档进程；每个工作台保留自己的 Cookie 输入和验证入口，需在对应工作台单独验证。

Cookie 文件等同于登录凭据，只保存在受控本机，不发送给他人，不放入仓库、聊天、日志或结果目录。导入/导出不会把 Cookie 写入 LocalStorage。

## 调试请求

选择接口，填写技术上必要的员工号、日期或锁班参数，点击发送请求。页面同时显示 HTTP 方法、最终 URL、状态码、响应 Headers、用户友好的表格/摘要以及原始 JSON 或 HTML。锁班提交和通过仍是两个独立写操作：提交成功只表示生成待审批记录；需要通过时再调用“通过指定待审批锁班”，由服务按同一员工、类型和日期时间定位记录并回查确认已锁。接口文档不会替你批量操作、解锁或处理冲突；批量业务使用独立工作台。

API 文档的生产请求仍由 Python `requests` 发送，但请求头会显式携带浏览器 User-Agent，不会使用 `python-requests/...` 默认标识；OA 粘贴完整 cURL 时优先沿用其中的 User-Agent，纯 Cookie 输入才使用默认浏览器 User-Agent。

## 万能查询

机器人、CLI 和其他受控本机程序可使用 `/api/universal-query/v1` 的标准 JSON 接口，而不是消费调试页面的原始正文和响应 headers。先读取 `GET /operations`，按每个操作的 `minimumInput` 向用户收集最少字段；再向 `POST /sessions/<systemId>` 载入 Cookie/cURL，并向 `POST /executions` 提交 `operation` 与 `parameters`。固定和自动参数不需要传入，Catalog 默认值会自动补齐。查询结果只有摘要和表格，不回传 Cookie、请求 URL、原始响应或调试 headers；渐进操作返回 `runId` 后以 `GET /executions/<runId>` 轮询。读写操作都会列出，调用 `risk=write` 的操作前仍需取得当前对象和动作授权。完整请求示例见 `spec/user/universal-query/manual.md`。

飞行人员信息查询的运行资格接口默认包含当前和历史资格，等价于门户勾选“查看历史资格”。培训记录接口在文档中按页单次调用；要读取全部分页，请使用“飞行人员信息查询（皇帝版）”工作台。

CAAC 的“有效飞行员分页列表”支持按姓名和档案号筛选，并按当前返回字段展示表格。“按姓名查询单个飞行员详情”先查询列表：姓名唯一时自动使用列表返回的 `pilotId` 获取详情；重名时填写档案号继续筛选，仍不唯一则停止。详情的基础字段、资质树、教育、工作、检查和打印记录按当前响应分别显示，不需要手工记忆飞行员 ID。

资质监控按资质查询分为资质运行类、资质资格类、资质特殊类。每个子类是一个独立入口，资质代码固定；可填写员工号、状态、基地、机队等筛选并修改 `pageNum`、`pageSize`。返回结果显示当前页 PageInfo 摘要和该子类实际返回的全部 JSON 字段。API 文档只调试分页 JSON，不下载原生 Excel；需要把当前全部子类分别导出为 Excel 时使用“资质监控（皇帝版）”。

OA 提供“获取全部 OA 数量”和“按数量点击 OA 已阅”两个入口。前者扫描全部分页，显示 OA 总数、可处理公文数、跳过数和各模块数量。后者填写任意正整数：填 1 处理一条，填其他数处理对应数量，不设置最大值；输入数大于当前可处理公文数时自动处理全部可处理公文。

SOC 随机置位目录包含站点拼音建议、申请原因列表、动态航班、人员与业务校验和单条提交。站点建议按拼音输入；航班下拉返回的复合 value 由执行器原样保留，不能只填写显示的航班号。申请原因按页面当前静态字典选择，提交属于写操作，只在 owner 当次授权后执行；HTTP 200 不是成功判据，只有响应 `message=录入成功！` 才显示业务成功。需要批量导入时使用独立的“SOC 随机置位批量工作台”，API 文档不会代替批量工作台自动提交。

按数量点击开始后，页面先显示全量扫描状态；扫描完成后显示本次目标。执行器只处理 `DOC/official-document`，其他模块跳过，并按列表顺序逐条调用已阅。一条返回后，该条标题、模块、状态和结果立即追加到结果表，再发送下一条；不会等整个批次完成后一次性显示。结果表默认自动跟随到最底部；用鼠标、滚轮或触控向上滚动后会暂停自动跟随，重新滚到底部后恢复。已阅单条请求发生任何异常时都记录当前条目失败并继续；只有登录会话失效时停止后续派发。

## Markdown 导出

点击“导出 Markdown”得到一个单文件文档，内容包括各系统会话验证与保活请求、当前模块、端点真实执行链路、模块相关请求、参数、响应契约、技术说明及原始目录 JSON。导出不需要启动本地后端，也不包含粘贴的 Cookie、真实响应或人员数据，适合人类阅读和文本模型分析。

如需同时获得 APP 操作手册、开发规格、系统架构和 API 文档，使用工具首页的“下载开发文档”。它下载构建时生成的 `csn2api开发者文档-YYYY-MM-DD.md`，是一个合并文件。
