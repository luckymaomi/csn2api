# 工具首页用户手册

首页品牌为“csn2api”，目录直接展示当前已登记工具。每个工具卡片显示用途、状态、打开入口和下载图标，顶部提供 API 文档、下载开发文档、主题切换和 GitHub。

通过 `start_index.py` 打开时，工具卡片进入说明和独立 ZIP 下载页。通过 `start_all.py` 打开时，工具卡片直接进入真实工作台，API 文档进入统一网关下的调试页。

点击工具卡片的下载图标会下载该工具自己的 ZIP。解压后打开根目录 index.html 查看启动说明，按说明安装 requirements.txt 并执行 `python start.py` 进入真实工作台。

局域网首页和工作台可以多人访问与操作，任务状态和结果共享。第一位进入任一工作台的 IP 显示为当前使用者；其他 IP 可以看到提示并主动“接管使用”，不会被拦截。接管不停止已有任务或清除会话；默认无活动 3 分钟且无任务运行后也可自动换人。状态条提供 API 文档入口和“结束使用”，当前使用者无任务运行时可结束；Cookie 验证由各应用自己的页面完成。

点击“下载开发文档”保存 `csn2api开发者文档-YYYY-MM-DD.md`，日期取下载当天。单文件包含系统架构、重建说明、APP 开发规格、用户手册及当前 API catalog 生成的完整接口文档，可用目录跳转。文件在构建时已经合并完成，不需要解压，也不包含源码、业务模板或登录凭据。

维护者只需编辑 src/tool/tools-data.ts 管理首页目录；站点门禁配置位于 src/site-visibility.ts 的 homepage.patternGate。Skill 不直接生成首页卡片；SOC 随机置位批量助手与其他工具一样通过 tools-data.ts 登记，并使用独立的 SOC 会话和接口实现。
