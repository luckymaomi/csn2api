# 航班明细查询（皇帝版）

## 启动

解压独立应用，在应用目录运行：

```powershell
pip install -r requirements.txt
python start.py
```

页面只监听本机 `127.0.0.1`。

## 验证登录

在已登录 IEB 的浏览器 Network 中复制任意 `ieb.csair.com` 请求的 cURL，粘贴到凭据框并点击“验证凭据”；也可以直接粘贴包含 `JSESSIONID` 和 `iebJSid` 的 Cookie Header。验证成功后页面显示当前登录人和独立保活状态。

## 准备输入

输入表格必须只有以下四列：

| 员工号 | 姓名 | 开始年月 | 结束年月 |
| --- | --- | --- | --- |
| 900001 | 示例甲 | 2026/1 | 2026/10 |
| 900002 | 示例乙 | 2023/05 | 2026/08 |

月份支持 `YYYY/M` 和 `YYYY/MM`。可上传 Excel，也可切换到粘贴模式粘贴带表头的制表符或逗号分隔表格。点击“数据检查”确认有效人员和计划查询的人员/月数量。

Excel 模板请在纯前端工具详情页点击“下载 Excel 模板”获取。模板带有一行合成格式示例，填写前请覆盖或删除该行；工作台仅负责上传填写后的文件。

## 查询和导出

点击“开始查询”后，系统按人员和月份严格串行读取 IEB 月度明细。结果会持续追加并分批保存，页面只加载当前分页窗口（状态每页 50 条、明细每页 100 条），不会一次渲染全部航班行。普通月份失败会继续后续任务；登录失效或点击“终止”后停止新的请求。

结果 Excel 包含 `航班明细` 和 `查询状态` 工作表；航班明细首列为序号，随后是姓名、员工号和门户字段，人工飞行方式完整保留。查询完成、终止或会话失效后，点击“下载查询结果”获取最近已保存文件。

## 本地接口

- `POST /api/session/verify`
- `POST /api/check-data`
- `POST /api/run`
- `GET /api/status`
- `GET /api/results?kind=status|detail&offset=0&limit=50`
- `POST /api/stop`
- `GET /api/download/result`
