# 飞行经历时间查询

首页选择“飞行经历时间查询”，可进入局域网工作台或下载独立应用。独立应用解压后安装 requirements.txt，执行 `python start.py`。

1. 在已登录飞行门户 F12 Network 复制完整 Copy as cURL，粘贴并验证凭据。
2. 上传员工号、姓名两列 Excel，或选择粘贴输入，每人一行，例如 `900001 示例姓名`。支持直接粘贴表头，无需日期。
3. 可先检查数据，再开始查询。重复员工号及无效行提示并跳过。
4. 下载完整结果。每人保留页面当前返回的汇总、历史合计、年度和月份全部行，前面加员工号、姓名；表头、原始顺序、时间和空值保持原样。“处理记录”保存失败、跳过和未查询说明。

详情页提供两列模板，填写前覆盖合成示例。每人完成后即可下载已有结果；“终止”在当前请求结束后停止新查询。会话失效后重新复制凭据。结果保存在本应用 results 目录。工具只读取当前“飞行经历时间”页，不点击年度或月份继续查询逐航班明细。
