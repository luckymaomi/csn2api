# CAAC 飞行员全量信息导出

## 启动

在独立 APP 目录执行：

```powershell
pip install -r requirements.txt
python start.py
```

工作台只监听 `127.0.0.1`。

## 使用

在 CAAC 人员管理页面按 F12 打开 Network，刷新已登录人员列表，选择 `fsop.caac.gov.cn` 请求复制完整 cURL，粘贴后点击“验证凭据”。也可以直接粘贴包含 `yzzzm`、`JSESSIONID`、`home` 的 Cookie Header。验证后可以复制当前页规范化凭据；刷新页面或会话失效后不再保留。

点击“开始全量抓取”后，工具先读取所有有效飞行员的动态分页列表，再按 `pilotId` 严格串行获取每个人详情。列表页数、人员数量、详情字段和记录数量都由接口实时返回，不能按当前 409 人或 41 页假设。

详情中的照片 URL 只作为普通文本列保留，不下载或嵌入图片；资质树、教育经历、工作经历、检查记录等数组以同一单元格内的纵向文本保存。每完成一人就原子保存一次检查点 Excel，后续出现的新字段会动态新增为列。单个人请求失败会写入失败原因并继续；登录凭据失效或进程异常时保留最后一次完整保存的已完成人员结果。

当前 CAAC 已确认接口没有稳定的当前登录人字段，因此页面会明确显示“未从 CAAC 已确认接口识别”，不会猜测账号姓名。
