# CAAC 飞行员信息导出

## 启动

在独立 APP 目录执行：

```powershell
pip install -r requirements.txt
python start.py
```

工作台只监听 `127.0.0.1`。

## 登录凭据

在 CAAC 人员管理页面打开 Network，刷新已登录人员列表，复制一条 `fsop.caac.gov.cn` 请求的完整 cURL，粘贴后点击“验证凭据”。也可以粘贴包含 `yzzzm`、`JSESSIONID`、`home` 的 Cookie Header。

验证成功后显示当前接口人数、验证时间、Cookie 字段数和保活倒计时，并可复制当前页规范化凭据。当前已确认接口没有稳定的登录人字段，因此登录人显示“未识别”。

## 全量抓取

选择“全量抓取”，点击“开始抓取”。工具动态读取当前账号范围内的分页列表，再按每个列表记录的 `pilotId` 严格串行获取详情。

## 名单抓取

点击“下载名单模板”。模板包含：

- `姓名`：必填。
- `档案号`：选填，重名时用于唯一归属。

模板不预填人员。填写后选择“名单抓取”，上传 `.xlsx` 或 `.xlsm` 文件，可先点击“检查名单”，再开始抓取。工具按姓名精确筛选候选；填写档案号时同时精确核对档案号。无匹配或无法唯一归属的行记录失败，后续人员继续处理。

## 结果

人员结果区显示与导出 Excel 相同的动态列和值。表格可以横向和纵向滚动，每页 50 人；运行中默认跟随最新结果，手动向上滚动或切换分页后保持当前位置。活动日志采用相同的跟随规则。

Excel 一人一行，基础信息使用中文业务列，资质树保留层级，教育、工作、航线、训练、检查和执照记录在各自单元格内逐条换行。接口新增字段会动态加入列，未映射字段保留原始字段名。

每完成一人即原子保存一次检查点 Excel。普通单人错误写入失败原因并继续；登录凭据失效或用户停止后，工具停止派发后续请求并保留已经完成的结果。
