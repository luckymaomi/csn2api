# CAAC 飞行员全量信息导出

## 启动

在独立 APP 目录执行：

```powershell
pip install -r requirements.txt
python start.py
```

工作台只监听 `127.0.0.1`。

## 使用

在 CAAC 人员管理页面按 F12 打开 Network，刷新已登录人员列表，选择 `fsop.caac.gov.cn` 请求复制完整 cURL，粘贴后点击“验证凭据”。也可以直接粘贴包含 `yzzzm`、`JSESSIONID`、`home` 的 Cookie Header。验证后可以复制当前页规范化凭据；刷新页面或会话失效后不再保留。

点击“开始全量抓取”后，工具先读取所有有效飞行员的分页列表，再按 `pilotId` 严格串行获取每个人详情。列表页数、人员数量、详情字段和记录数量均根据接口实时响应动态更新。

导出的 Excel 一人一行。基础信息使用中文业务列，资质树保留层级，学习简历、工作经历、机长航线、应急生存、熟练检查和正式执照打印记录在各自单元格内逐条换行。详情接口返回的文件 URL、记录 ID、审计字段、状态码和页面未展示字段都会保留；工具不会请求 URL 指向的文件。未识别的新字段会带原始字段名保留。

每完成一人就原子保存一次检查点 Excel，后续出现的新字段会动态新增为列。单个人请求失败会写入失败原因并继续；登录凭据失效或进程异常时保留最后一次完整保存的已完成人员结果。开始全量抓取前，应核对凭据验证后显示的有效人员数是否符合当前机构范围。

当前 CAAC 已确认接口没有稳定的当前登录人字段，因此页面会明确显示“未从 CAAC 已确认接口识别”，不会猜测账号姓名。
