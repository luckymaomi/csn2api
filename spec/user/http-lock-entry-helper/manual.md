# 锁班皇帝（新）使用手册

## 启动

在应用目录安装依赖并启动：

```powershell
pip install -r requirements.txt
python startapp.py
```

程序在本机 `127.0.0.1` 的随机端口启动，并自动打开工作台。

## 登录凭据

1. 在 Chrome 或 Edge 登录飞行门户。
2. 按 `F12` 打开 Network，刷新页面。
3. 右键任意 `ieb.csair.com` 已登录请求，选择 `Copy > Copy as cURL`。
4. 把完整内容粘贴到工作台，点击“验证凭据”。

验证成功后页面显示当前登录人、动态类型数量、类型版本和保活倒计时。当前页可以复制规范化 Cookie；刷新页面、会话失效或本地服务退出后需要重新验证。

## 准备数据

Excel 必需表头：

```text
员工号  姓名  锁班类型  开始日期  结束日期
```

锁班类型可以填写 code、`code-名称` 或门户完整名称。工作台每次验证凭据时从门户加载当前类型，并按每行匹配到的 code 原样录入。

需要指定分钟时增加“开始时间”和“结束时间”，格式为 `HH:mm`。留空时 CRM 使用 `08:30-16:30`，其他类型使用 `08:59-19:59`。

按月份选择非连续日期时增加：

```text
时间模式  月份  锁班日期  开始时间  结束时间
```

可以在“备注”列填写每行原因，也可以在页面填写统一备注。优先级为每行备注、统一备注、门户默认原因，最长 60 个字符。

粘贴模式推荐直接复制五列：员工号、姓名、锁班类型、开始日期、结束日期。员工号白名单留空时处理全部有效记录。

## 数据检查

点击“数据健康检查”后，页面显示有效数、无效数和逐条原因。修改输入后可以重新检查。点击“开始录入”时会重新读取当前内容，只处理有效记录。

## 开始录入

程序按输入顺序严格串行处理，每条记录按 Excel 中的类型生成一次锁班提交。门户返回普通结果时记录成功，返回冲突时记录冲突；其他单条错误记录失败并继续。会话失效或点击“终止”后停止派发后续请求。

勾选“提交成功后直接通过并锁班”时，程序先保存待审批结果，再执行通过并查询确认已锁。通过失败会单独显示，已经生成的待审批结果仍保留。

进度区显示总数、完成、成功、失败和当前人员。结果与日志默认跟随最新内容，手动向上滚动后保持当前位置。

## 结果与下一批

每条门户结果产生后立即写入结果 Excel。在线结果和 Excel 的“冲突原因”列显示门户返回的具体冲突内容；普通结果该列为空，处理或归属异常仍显示在“说明”列。运行开始后即可下载，中途终止也保留已经完成的记录。

批次完成或终止后，当前有效 Session 继续保留。可以更换 Excel 或粘贴下一批数据，再执行检查和录入。

## Agent HTTP 入口

`POST /api/start` 可串联凭据验证、数据检查和开始录入。Excel 内容使用 Base64 字段 `excelBase64`，粘贴内容使用 `pastedText`。通过 `GET /api/status` 轮询进度，通过 `GET /api/download/result` 下载结果。
