# 局域网统一工作台使用手册

## 启动

在仓库根目录运行：

```powershell
python start_all.py
```

终端会显示本机和局域网访问地址。把局域网地址发给同事即可；不要单独转发各子服务的随机端口。停止时回到启动终端按 `Ctrl+C`，程序会一起关闭全部工作台。

浏览器访问终端显示的根地址后会进入 `/tool/` 首页；这是首页样式和脚本的规范资源路径。

常用参数：

```powershell
python start_all.py --port 4567 --idle-minutes 3
python start_all.py --no-build --no-open
```

## 占用

所有人都能查看首页。第一位进入任一具体工作台的 IP 会取得使用权，同一 IP 可以继续打开其他工具；其他 IP 会看到“当前工作台正在使用中”和使用者 IP，但看不到对方的身份、Cookie、结果或日志。

页面状态条会自动续期。操作结束且没有任务运行时，点击“结束使用”；如果任务仍在运行，需要等待完成或先按该工具规则停止。连续 3 分钟没有活动且没有任务运行后，下一位访问者可以接管，接管时上一位的全部内存 Session 会被清空。

## Cookie 文件

在任一工作台的局域网状态条，或 API 文档页头，点击“导入 Cookie”选择 `csn2api-cookies-*.json` 或同内容 TXT。系统会逐项验证，并把成功项分发给同一系统的工作台。点击“导出 Cookie”可保存当前 API 文档中仍有效的规范化 Cookie。

Cookie 文件包含明文登录凭据，只放在受控本机，不发送给他人，不上传仓库或聊天。服务重启后可重新导入；导入失败时按页面显示的具体系统或工作台重新复制标准 cURL。
