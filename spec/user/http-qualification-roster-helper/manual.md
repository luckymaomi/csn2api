# 运行资质人员名册

## 启动

解压独立应用，在应用目录运行：

```powershell
pip install -r requirements.txt
python start.py
```

页面只监听本机 `127.0.0.1`，不启动浏览器自动化。

## 验证登录

在已登录 IEB 的浏览器 Network 中复制任意 `ieb.csair.com` 请求的 cURL，粘贴到凭据框并点击“验证并加载筛选”。也可以粘贴 Cookie Header。验证成功后页面显示当前登录人、动态筛选项、动态运行资格和保活倒计时；凭据区提供当前页复制按钮。

## 筛选和查询

筛选字段与门户技术资料页面保持一致。默认执飞机型为 `777`，在职状态为全部四项。运行资格列表来自门户当前响应，默认勾选指定的 13 个代码；可以搜索、清空或重新恢复默认选择。

点击“查询并生成名册”后，系统按选中顺序逐个运行资格查询和普通人员导出。页面逐项显示查询人数、完成数、失败数和人员资质明细。一个资格失败会记录原因并继续后续资格；会话失效才会停止后续请求。

## 导出结果

结果 Excel 为单 Sheet，列为：`序号`、`员工号`、`姓名`、`资质类别`。名单不做去重；同一员工同时具备多个选中资格时保留多行，每行只标记对应的当前资格代码。每个资格完成后文件立即更新，任务结束或停止后可下载当前结果。

结果表和日志均为固定高度滚动区域。向上滚动会暂停自动跟随，回到底部后恢复。

## 本地接口

- `POST /api/session/verify`：验证 Cookie 并读取动态筛选和运行资格。
- `POST /api/run`：提交 `filters` 与 `qualificationCodes`，按资格逐项生成名册。
- `GET /api/status`：轮询当前会话、进度、结果和日志。
- `POST /api/stop`：停止后续资格派发。
- `GET /api/download/excel`：下载当前已保存的四列 Excel。
