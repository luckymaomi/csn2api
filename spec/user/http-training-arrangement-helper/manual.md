# 训练安排查询（HTTP版）用户手册

## 启动和验证

下载独立应用并解压，安装依赖后运行：

```powershell
pip install -r requirements.txt
python start.py
```

在已登录 IEB 的浏览器 Network 中复制任意请求的 Copy as cURL，或复制 Cookie Header，粘贴后点击“验证凭据”。验证成功会自动加载当前门户训练类别。

## 一键导出区域默认配置

查询条件下方的“区域默认查询范围”会以单列逐项展示预设的 11 个业务类型和 13 个训练科目，每个类型及其所属科目在同一行说明，未验证凭据时也可以直接查阅。确认结束日期后，点击“一键导出区域默认配置”，不需要逐个切换训练类别。查询固定覆盖本周、本月和本年度；页面实时显示当前业务类型、训练科目、周期、页码和已取得的数据。

“分类汇总”按业务类型展示本周、本月和年度的人次及通过率；下面的明细表保留门户返回的全部字段并增加“区域类型”和“所属周期”。同一安排即使同时属于本周、本月和年度，也只显示一条明细。只有“员工号/姓名”同时包含员工号和括号内姓名的行才计为有效数据；训练状态“完成”计为通过，“终止”计为不通过。没有有效记录时通过率显示 `/`，空表和“没有训练班人员信息”等门户占位行不计为人次。

全部查询完成后点击“导出 Excel”。文件包含“分类汇总”和“明细”两个 Sheet。若当前门户缺少默认配置中的科目，页面会列出缺失项并禁用一键导出，需先核对门户类别是否改名。

## 单类别查询

原有查询仍可使用：选择一个训练类别、时间范围和结束日期，点击“开始查询”。该模式只查询当前选择的类别，并按所选周期展示和导出。

## 停止和异常

“停止”在当前 HTTP 请求返回后生效，不会强制中断已经发出的请求。登录失效、门户表头变化或出现“完成/终止”以外的训练状态时，工具停止后续默认查询并显示错误，不会输出可能失真的最终统计。
