# 从零重建与验收

## 恢复与重新实现

从仓库恢复需要源码、锁定依赖、本地静态库、模板、共享协议和运行时。仅有合并文档时，可以按业务与接口契约重新实现；要复原同一产物，还需这些资源和完整代码。当前规格没有逐条穷尽所有 HTML 解析分支；catalog、合成测试和人工业务核对共同约束重建，不声称已经完成脱离源码的独立重建。

## 源码恢复

在新环境安装 Node.js 22、Python 3.12 与 Git，取得完整仓库后执行：

```powershell
npm.cmd ci
python -m pip install -r requirements.txt
npm.cmd run verify
```

Node/Python 版本与 `.github/workflows/deploy-pages.yml` 一致；根目录 requirements 固定本地测试与 HTTP/Excel 依赖。各独立包安装自己的 requirements。构建不能从旧 `dist/` 回填源码；`dist/` 可删除后重新生成。

`python start_index.py --no-build --no-open` 验证静态站点；`python start_all.py --no-build --no-open` 验证网关及全部子服务；单工具则解压 `dist/exports/<entry>.zip` 后执行包内 `start.py`。验证结束按 Ctrl+C 关闭，确认本轮监听端口释放。静态站点无法代替 Python 执行器执行生产请求。

## 实现顺序

1. 读取[系统架构](architecture.md)、目标 APP 的 dev/user 和对应 catalog；区分输入身份、生产内部 ID、请求事实与本地组合流程。
2. 建立稳定模型与脱敏合成用例，写明给定输入的成功、空结果、失效、歧义和异常期望。身份不唯一时拒绝，不选第一条；分页依据响应收敛，不猜总页数。
3. 实现各系统 protocol core，先保护请求字段、重复参数、响应结构与归属，再供 API 和 APP 两个入口复用。接口文档与 core 不能各维护一套命令式请求实现。
4. 实现 APP 的输入、runner、manager、文件保存与 server。状态响应与页面同源，下载只访问 manager 登记的结果；停止、部分失败和检查点按对应工具规格实现。
5. 实现 API 参数与动态响应展示、Cookie 生命周期及万能查询。机器接口使用当前 catalog 的操作和默认值，不能另造固定操作清单。
6. 接入共享主题、保活、工具登记、protocol 分发和网关。独立包必须包含启动器、Python 依赖、模板、全部本地资源和对应 core。
7. 运行自动合同，再以当次授权 Session 分别验证 APP 与 API 用户入口。生产写操作需要对象、参数和动作的明确授权；自动测试不提供这种授权。

## 最小行为验收

| 场景 | 必须保留的结果 |
| --- | --- |
| 飞行经历时间页包含汇总、年度、月份和空值 | 保留当前返回的全部行列与顺序，不补不存在的年月、不重复累加父子汇总；主表与处理记录分开 |
| 航班明细两人覆盖多个月 | 每人时间轴最多一次，各月按序请求；多行人工飞行方式不丢失，未查询月份有状态，收口后 Excel 与分页结果一致 |
| 同一员工多资格、同一安排多周期 | 名册保留跨资格多行；训练统计按本工具去重与人次规则处理，不能混用两种去重口径 |
| 锁班提交成功但通过失败 | 保留已产生的待审批结果，明确记录通过失败；不以提交成功冒充已锁 |
| OA 公文与其他模块混合 | 只有当前确认公文进入已阅；其他模块跳过，每条最多一次，普通失败继续、失效停止 |
| CAAC 同名人员 | 根据档案号消歧，仍不唯一则失败；动态详情字段及追踪列完整保留 |
| SOC HTTP 200 但业务 message 失败 | 当前行失败；不能仅凭状态码算成功，不重试写入 |
| 网关接管/关闭 | 接管只变使用提示；关闭网关同时关闭全部本轮子服务，不遗留线程或端口 |

这些是重建入口条件；完整规则和导出结构见各工具规格，参数与响应见合并文档 API 段落。固定大小、文件测量或私人业务样本不能代替可重放的输入和期望。

## 验收证据与边界

`npm.cmd run verify` 检查目录同步、严格类型、TypeScript/Python 测试、独立分发与确定性构建。独立 ZIP/网关合同使用本地临时服务检查资源和关闭，不调用生产系统。APP/API 共享协议合同检查声明与请求实现的一致性。

真实验收使用[统一验收说明](../dev/real-api-verification/README.md)及被 Git 忽略的本地凭据文件；当前该入口不包含 SOC，SOC 单独按其领域规约验收。真实登录入口、权限、当前页面及业务数据必须在新环境重新核对；HTTP 200 和合成测试通过都不能证明生产业务成功。
